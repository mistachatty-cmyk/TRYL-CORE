TRYL Ecosystem API Reference

A comprehensive guide to the custom functions driving the TRYL E-Commerce, Theme, and Integrations ecosystem.

Backend & Integrations (backend/functions.php)

tryl_register_core_product_categories()
Registers core product categories for the TRYL store. Ensures that 'Men', 'Women', 'Kids', and 'Hats & Accessories' categories exist upon initialization.
Returns: void
tryl_handle_prayer_request_submission()
Handles the submission of the Prayer Request form. Verifies the nonce, sanitizes input, sends notification emails, and saves the request as a 'prayer_request' custom post type.
Returns: void
tryl_register_prayer_cpt()
Registers the 'prayer_request' Custom Post Type. Sets up a private CPT accessible via the admin dashboard for managing user-submitted prayer requests.
Returns: void
tryl_prayer_meta_box_html( $post )
Renders the HTML for the 'Prayer Details & Response' meta box. Displays the requester's details, their prayer, and provides a form for admins to send a reply via email.
Parameter Type Description
$post WP_Post The current post object.
Returns: void
tryl_save_prayer_reply( $post_id )
Saves the data from the 'Prayer Details & Response' meta box. Handles sending the reply email to the requester and updating the prayer request's status and public visibility metadata.
Parameter Type Description
$post_id int The ID of the post being saved.
Returns: void
tryl_register_printful_route()
Registers the custom REST API route for Printful webhooks. (Route: POST /wp-json/tryl/v1/printful-sync).
Returns: void
tryl_verify_printful_webhook( $request )
Verifies the authentication token for incoming Printful webhooks by comparing the 'token' query parameter against the stored setting.
Parameter Type Description
$request WP_REST_Request The incoming REST request.
Returns: bool True if authorized, false otherwise.
tryl_handle_printful_sync( $request )
Processes incoming Printful webhook payloads. Handles 'package_shipped', 'package_returned', 'order_failed', and 'order_canceled' events to automatically update WooCommerce order statuses and metadata.
Parameter Type Description
$request WP_REST_Request The incoming REST request.
Returns: WP_REST_Response | WP_Error Response object or Error if invalid.
tryl_ensure_payment_gateways( $gateways )
Enforces required payment gateways in WooCommerce.
Parameter Type Description
$gateways array Array of available payment gateways.
Returns: array Filtered array of payment gateways.

Theme Functions (tryl-theme/functions.php)

tryl_theme_setup()
Sets up theme defaults and registers support for various WordPress features (title tags, thumbnails, custom logo).
Returns: void
tryl_enqueue_assets()
Enqueues the theme's stylesheets and scripts. Includes GSAP and ScrollTrigger for custom animations.
Returns: void
tryl_hero_section_shortcode( $atts )
Hero Section HTML Shortcode. Renders the GSAP-animated hero portrait and typography section.
Parameter Type Description
$atts array Shortcode attributes (image, text_left, text_right, btn_text, btn_url).
Returns: string HTML output of the hero section.
tryl_prayer_wall_shortcode()
Public Prayer Wall Shortcode. Displays approved anonymous prayer requests in a grid layout.
Returns: string HTML output for the prayer wall grid.
