# Enhanced Size Selection for TRYL Shop Page

## Overview
Implement enhanced size selection functionality on the shop page that allows users to:
1. Click on size buttons that slide out or toggle to show available sizes
2. Select a size and automatically add to cart via AJAX
3. Get visual feedback via GSAP animations (glow, scale with number tick)
4. Trigger mini-cart drawer slide when cart is updated
5. Maintain mobile responsiveness and follow existing design patterns

## Current State Analysis

### Shop Page Structure
- Uses `[tryl_3d_shop]` shortcode defined in `tryl-ecommerce-core.php`
- Product cards generated by `tryl_get_core_product_card_html()` function
- Variable products currently show "Select Size" button with inline dropdown
- Simple products show "Add to Cart" button

### Existing Systems
- AJAX add-to-cart handler: `tryl_ajax_add_to_cart_handler()`
- Mini-cart drawer with GSAP animations in `tryl-core.js`
- GSAP already enqueued globally
- Cart count updating system in place

## Implementation Plan

### 1. Modify Product Card Template
Update `tryl_get_core_product_card_html()` in `tryl-ecommerce-core.php` to:
- Replace "Select Size" button with size toggle mechanism
- Add container for size buttons that slide out on hover/click
- Keep existing CSS classes for consistency

### 2. Enhanced Size Selector JavaScript
Create new functionality in `tryl-core.js`:
- Event delegation for size button clicks
- Slide-out animation for size options using GSAP
- AJAX add-to-cart on size selection
- Visual feedback animations (glow, scale with cart count)

### 3. Visual Feedback System
Implement three optional feedback styles (configurable via dashboard):
- **Glow**: Product card pulses with accent color
- **Scale with Number**: Cart icon scales up and shows incrementing number
- **Mini Pulse**: Subtle scale animation on cart icon

### 4. Mobile Responsibility
- Ensure touch-friendly size buttons
- Slide-out animations work on mobile
- Maintain existing breakpoint patterns

### 5. Configuration Options
Add dashboard options for:
- Size selector style (slide-out, toggle, dropdown)
- Feedback animation type (glow, scale, pulse)
- Animation duration and easing

## Files to Modify
